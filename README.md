# javascript-lotto-precourse

간단한 로또 발매기를 구현하는 프로젝트입니다.

[test.mov](test.mov)

## 📋 기능 목록

### 입력

#### 1. 로또 구입 금액 입력

- 구입 금액을 입력받습니다.
- **정상 경우**
    - 1,000원 이상의 금액을 입력
    - 1,000원 단위로 입력
- **예외 경우**
    - 입력값이 공백인 경우 → `[ERROR] 구입 금액을 입력해주세요.`
    - 숫자가 아닌 경우 → `[ERROR] 구입 금액은 숫자여야 합니다.`
    - 1,000원 미만인 경우 → `[ERROR] 구입 금액은 1,000원 이상이어야 합니다.`
    - 1,000원 단위가 아닌 경우 → `[ERROR] 구입 금액은 1,000원 단위여야 합니다.`
    - 소수인 경우 → `[ERROR] 구입 금액은 정수여야 합니다.`

```
구입금액을 입력해 주세요.
8000
```

#### 2. 당첨 번호 입력

- 당첨 번호 6개를 쉼표로 구분하여 입력받습니다.
- **정상 경우**
    - 1~45 사이의 서로 다른 6개 숫자를 입력
- **예외 경우**
    - 입력값이 공백인 경우 → `[ERROR] 당첨 번호를 입력해주세요.`
    - 6개가 아닌 경우 → `[ERROR] 당첨 번호는 6개여야 합니다.`
    - 숫자가 아닌 경우 → `[ERROR] 당첨 번호는 숫자여야 합니다.`
    - 범위 밖(1~45)인 경우 → `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`
    - 중복된 번호가 있는 경우 → `[ERROR] 당첨 번호에 중복된 숫자가 있습니다.`

```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```

#### 3. 보너스 번호 입력

- 보너스 번호 1개를 입력받습니다.
- **정상 경우**
    - 1~45 사이의 당첨 번호와 겹치지 않는 숫자를 입력
- **예외 경우**
    - 입력값이 공백인 경우 → `[ERROR] 보너스 번호를 입력해주세요.`
    - 숫자가 아닌 경우 → `[ERROR] 보너스 번호는 숫자여야 합니다.`
    - 범위 밖(1~45)인 경우 → `[ERROR] 보너스 번호는 1부터 45 사이의 숫자여야 합니다.`
    - 당첨 번호와 중복되는 경우 → `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.`
    - 소수인 경우 → `[ERROR] 보너스 번호는 정수여야 합니다.`

```
보너스 번호를 입력해 주세요.
7
```

### 처리

#### 1. 로또 발행

- 구입 금액을 1,000으로 나누어 로또 개수를 계산합니다.
- 계산된 개수만큼 로또 티켓을 생성합니다.
- 각 로또 티켓은 1~45 사이의 중복되지 않는 6개 숫자로 구성됩니다.

#### 2. 당첨 판정

- 각 로또 티켓과 당첨 번호를 비교합니다.
- 일치하는 번호의 개수를 계산합니다.
- 5개 일치 시 보너스 번호 일치 여부를 추가로 확인합니다.

#### 3. 통계 계산

- 등수별(1~5등) 당첨 개수를 집계합니다.
- 총 상금을 계산합니다.
- 수익률을 계산합니다(소수점 둘째 자리에서 반올림).

### 출력

#### 1. 로또 발행 내역 출력

- 발행한 로또 개수를 출력합니다.
- 각 로또 티켓의 번호를 오름차순으로 정렬하여 출력합니다.

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
...
```

#### 2. 당첨 통계 출력

- 등수별 당첨 현황을 출력합니다.

```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

#### 3. 수익률 출력

- 게임의 최종 수익률을 출력합니다.

```
총 수익률은 62.5%입니다.
```

## 🎯 당첨 기준

| 등수 | 조건                | 상금             |
|----|-------------------|----------------|
| 1등 | 6개 번호 일치          | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원    |
| 3등 | 5개 번호 일치          | 1,500,000원     |
| 4등 | 4개 번호 일치          | 50,000원        |
| 5등 | 3개 번호 일치          | 5,000원         |
